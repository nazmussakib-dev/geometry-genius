# Geometry Genius 🧮

An interactive geometry calculator built with **HTML, Tailwind CSS, and JavaScript**. Enter the required dimensions for different geometric shapes and instantly calculate their areas through an interactive interface.

## 🚀 Live Demo

[Geometry Genius](https://nazmussakib-dev.github.io/geometry-genius/)

## ✨ Features

* 🔺 Calculate the area of a triangle
* ▭ Calculate the area of a rectangle
* ▱ Calculate the area of a parallelogram
* ◇ Calculate the area of a rhombus
* ⬠ Calculate the area of a pentagon
* ⬭ Calculate the area of an ellipse
* ⚡ Get calculation results instantly
* 📱 Responsive and user-friendly interface
* 📐 View the formula for each geometric shape
